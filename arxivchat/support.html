常见问题

登录失败怎么办？

先确认网络可用，然后尝试切换登录方式（Apple / Google / 邮箱验证码）。如果只有某种方式失败，请把出现错误的时间点告诉我们，我们会查服务端日志。若提示“账号已被合并”，说明该登录方式已绑定到另一个账号，请改用原账号登录。

订阅没生效 / 换了设备看不到会员？

请在订阅页面点击“恢复购买”，并确认使用的是同一个 Apple ID。如果仍然无效，把购买记录截图（App Store → 账号 → 购买记录）发给我们。

怎么取消订阅？

打开 iOS“设置”→ 点击顶部 Apple ID → 订阅 → 选择 arXivChat → 取消订阅。取消后当前订阅期内权益仍然有效，到期不再续费。删除应用不会取消订阅。

怎么申请退款？

退款由 Apple 处理，访问 reportaproblem.apple.com 提交申请。我们无法直接操作退款。

AI 功能提示额度已用完？

摘要、AI 导读、翻译、日报和 PDF 处理对非会员设有每日次数限制，额度每日重置。如需无限使用，请订阅会员。

AI 回答不准确或翻译有问题？

AI 输出可能存在错误，请以论文原文为准。欢迎把具体的论文 ID 和问题发给我们，帮助改进。

PDF 打不开或下载失败？

请确认网络稳定，并检查设备剩余空间。若论文本身在 arXiv 上无法访问，我们也无法获取。可以在论文详情页尝试“在浏览器打开原文”。

收藏 / 阅读历史丢失？

请确认已登录同一账号，并在设置中开启 iCloud 同步。退出登录会清除本机缓存数据，重新登录后会从服务器重新同步。

怎么删除账号和全部数据？

打开设置 → 账号管理 → 删除账号。删除后账号无法恢复，服务器上的相关数据会在合理期限内清除。请注意：删除账号不会自动取消 Apple 订阅，需要单独在 iOS 订阅设置中取消。

推送通知收不到？

检查 iOS 设置 → 通知 → arXivChat 是否允许通知，以及应用内设置 → 通知是否开启了对应类别（每日更新 / 翻译完成 / 热门论文）。

支持哪些语言和设备？

支持简体中文、繁体中文、英语、日语、韩语、印尼语。iPhone、iPad 均可使用，需要 iOS 14 及以上版本。
