TimesUp 隐私政策

生效日期：2026-11-06
运营主体：Nanjing Zhuoben Technology Co., Ltd
联系邮箱：arxivchat@gmail.com

适用范围

TimesUp 是由家长在被管理的 iPhone 或 iPad 上设置屏幕时间规则的工具。每台设备分别授权和管理，不提供 TimesUp 账号登录、远程配对、远程定位或跨设备使用时长汇总。

保存在设备上的信息

TimesUp 在本机保存所选应用、类别或网站的系统标识，暂停状态、每日额度、重置时间、设备显示名称、语言与外观偏好，以及运行限制所需的本地状态。App 与其系统扩展通过同一 App Group 在本机共享相关设置。我们不会将这些屏幕时间规则或应用选择标识上传到我们的服务或 RevenueCat。

独立家长密码和恢复码以加盐摘要形式保存在设备钥匙串，不以明文保存在偏好设置中。我们无法读取你的原密码或恢复码，也无法通过服务器远程找回它们。

Apple 和 RevenueCat 购买处理

免费试用和永久解锁通过 Apple 的 App 内购买提供。Apple 处理购买确认及付款信息；TimesUp 使用 StoreKit 和 RevenueCat 验证购买、恢复权益、防止购买滥用，并进行购买统计分析。

RevenueCat 使用匿名 App User ID 以及交易、产品、权益、商店地区和币种等购买处理所需信息。当前 TimesUp 不向其设置姓名、邮箱、自定义可识别用户 ID 或广告标识符，也不将屏幕使用规则、家长密码、恢复码或声纹资料作为购买属性发送。

购买信息可能由 Apple 与 RevenueCat 按其服务、隐私政策及适用保留要求处理。我们不接收你的银行卡号或 Apple 账户密码。购买处理可能在你所在国家或地区以外进行，具体安排以服务商公开政策和实际服务配置为准。

Apple 隐私政策：https://www.apple.com/legal/privacy/
RevenueCat 隐私政策：https://www.revenuecat.com/privacy/

可选麦克风、声纹与生物识别

麦克风只在你主动使用声纹录入或验证时请求。声音比对在本机进行，临时录音用于本次处理后清理；声纹特征保存在设备钥匙串，可在家长安全设置中删除，不上传给 Apple 或 RevenueCat 用于本功能。

声纹匹配是可选、实验性的快捷验证，不校验朗读内容，也不具备防录音重放能力，可能误认其他声音。它不是强身份识别保证。家长密码始终作为可用方式保留。

可选 Face ID / Touch ID 使用系统认证接口。TimesUp 不取得系统人脸或指纹模板。请仅在设备录入的生物特征属于家长时启用；该选项默认关闭。

未请求的信息与广告

TimesUp 不请求定位、通讯录或相册权限，也不通过本 App 读取聊天内容。当前版本没有第三方广告或跨公司广告跟踪。若未来新增数据处理用途，我们会更新说明并按需要取得授权。

家长与儿童

本工具由家长设置和管理。涉及儿童或青少年屏幕时间授权时，按 Apple 系统流程及适用要求由监护人批准。我们不通过 TimesUp 要求儿童提交姓名、邮箱或手机号，也不提供儿童社交、聊天或用户公开发布内容的功能。

保留、删除与控制

你可以在家长管理页清除全部规则以停止监控和解除限制，也可以删除声纹资料、关闭快捷验证、调整权限。清除规则会保留家长密码和购买记录。

删除 App 不一定清除钥匙串内容；Apple 和 RevenueCat 的交易记录也不会因此自动删除。购买历史和试用资格仍可能用于恢复原有权益。涉及购买数据或你主动发给支持的信息的请求，可通过上述邮箱联系我们；我们可能需要合理的购买归属信息来处理，但请勿发送家长 PIN、恢复码、完整银行卡信息或 Apple 账户密码。

如果你主动联系支持，我们会处理你提供的邮箱、问题说明及必要的订单信息，仅用于响应请求、排查问题及满足适用保留要求。

网站托管

本支持网站由 GitHub Pages 托管。GitHub 可能按照其隐私声明处理 IP 地址等常规网站请求信息。本网站未添加广告、分析脚本或跟踪 Cookie。

GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

政策更新

功能或数据处理发生变化时，我们会更新本政策及生效日期。关于本政策或数据处理的问题，请联系 arxivchat@gmail.com。
