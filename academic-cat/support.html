常见问题

论文数据多久更新一次？

App 数据与 arXiv 官网保持同步，官网每次更新后触发同步，预计半小时内完成。论文相关时间为作者提交至 arXiv 的日期。只有工作日才更新「前一天」提交的论文，周五的论文需要下个周一才更新；周末以及美国联邦假日不更新。

登录失败怎么办？

先确认网络可用，然后尝试切换登录方式（Apple / 微信 / 邮箱验证码）。如果只有某种方式失败，请把出现错误的时间点告诉我们，我们会查服务端日志。若提示「账号已被合并」，说明该登录方式已绑定到另一个账号，请改用原账号登录。

AI 解读 / 翻译字数或次数用完？

非会员用户的 AI 解读、摘要翻译、PDF 翻译与日报设有每日次数限制，额度每日重置。开通会员可解锁不限次数使用。

PDF 翻译要多久？翻译件能保存多久？

翻译任务按论文篇幅排队处理，完成时间从几分钟到几十分钟不等。翻译件设有有效期（应用内显示「翻译件有效至」），请在有效期内下载或保存到本地，过期后需要重新生成。

会员没生效 / 换了设备看不到会员？

请在会员页面点击「恢复购买」，并确认使用的是同一个 Apple ID。如果仍然无效，把购买记录截图（App Store → 账号 → 购买记录）发给我们。

怎么取消订阅？

打开 iOS「设置」→ 点击顶部 Apple ID → 订阅 → 选择学术猫 → 取消订阅。取消后当前订阅期内权益仍然有效，到期不再续费。删除应用不会取消订阅。

怎么申请退款？

通过 App Store 完成的购买，退款由 Apple 处理，访问 reportaproblem.apple.com 提交申请。我们无法直接操作退款。

怎么把论文 PDF 发到我的邮箱？

在 PDF 阅读页底部点击「想稍后阅读？点击此处将 PDF 发送到您的电子邮件」，或先在设置中填写「论文接收邮箱」。请留意邮件可能在垃圾箱里。

收藏 / 阅读历史丢失？

请确认已登录同一账号，并在设置中开启 iCloud 同步。退出登录会清除本机缓存数据，重新登录后会从服务器重新同步。

怎么删除账号和全部数据？

打开设置 → 账号管理 → 删除账号。删除后账号无法恢复，服务器上的相关数据会在合理期限内清除。请注意：删除账号不会自动取消 Apple 订阅，需要单独在 iOS 订阅设置中取消。

推送通知收不到？

检查 iOS 设置 → 通知 → 学术猫是否允许通知，以及应用内设置 → 通知是否开启了对应类别（每日更新 / 翻译完成 / 热门论文）。

支持哪些语言和设备？

支持简体中文、繁体中文、英语、日语、韩语、印尼语。iPhone、iPad 均可使用，需要 iOS 14 及以上版本。
